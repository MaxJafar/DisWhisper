Native DisWhisper apps are now available for **Windows and macOS**, with the same workspace for Discord setup, local speech models, live transcripts, and meeting notes.

## Download and install

| Your computer | Download | Install |
|---|---|---|
| Windows 10 (2004+) / 11, x64 | [Windows installer](https://github.com/MaxJafar/DisWhisper/releases/download/v0.2.1/DisWhisper-0.2.1-windows-x64-setup.exe) | Run setup, then open **DisWhisper** from Start. A desktop shortcut is optional. |
| Mac with Apple Silicon (M1 or newer), macOS 13+ | [Mac Apple Silicon DMG](https://github.com/MaxJafar/DisWhisper/releases/download/v0.2.1/DisWhisper-0.2.1-macos-arm64.dmg) | Open the DMG and drag **DisWhisper.app** onto **Applications**. |
| Mac with Intel, macOS 13+ | [Mac Intel DMG](https://github.com/MaxJafar/DisWhisper/releases/download/v0.2.1/DisWhisper-0.2.1-macos-x86_64.dmg) | Open the DMG and drag **DisWhisper.app** onto **Applications**. |

The apps include their backend and runtime. **No separate Python, .NET, or Homebrew installation is needed.** Portable ZIPs are also attached; extract the complete Windows folder. Speech-model weights download in the app and are not included.

Windows packages are unsigned. Mac packages use ad-hoc signatures and are not notarized. If macOS blocks first launch, use **System Settings → Privacy & Security → Open Anyway**, following [Apple's instructions](https://support.apple.com/guide/mac-help/open-a-mac-app-from-an-unidentified-developer-mh40616/mac). Every installer and ZIP has a matching `.sha256` file.

## First meeting

1. Open **Connect Discord**, create your own bot, check its token, invite it, and select your server.
2. In **Models**, download **Whisper Base** and select **Use model**.
3. Connect from **Home**, join a voice channel, and use **`/join`**. Finish with **`/leave`** or **Finish meeting**.

See the [Windows quickstart](https://github.com/MaxJafar/DisWhisper/blob/v0.2.1/docs/windows-quickstart.md) or [Mac quickstart](https://github.com/MaxJafar/DisWhisper/blob/v0.2.1/docs/macos-quickstart.md). Updating the app preserves separately stored models, credentials, and transcripts. Local transcription uses the CPU without a cloud API key; cloud providers and Ollama meeting notes are optional.

## Changes in this release

- Native Swift/AppKit Mac app with the Windows pages, violet visual language, light/dark themes, and keyboard navigation.
- Branded Mac menu bar icon for reopening the workspace, finishing a meeting, and opening notes; closing the window keeps the bot running.
- Mac login Keychain credentials and a portable backend with bundled speech and Discord voice libraries.
- Windows installer with per-user installation, Start menu/desktop shortcuts, and uninstall support.
- Shared release builds for Windows x64, Mac arm64, and Mac x86_64; tested installer paths, portable ZIPs, checksums, and matching source archives.
- README featuring an actual capture of the AppKit UI with its labelled demo conversation.

## Verification and licenses

All platform builds must pass the Python tests, native Release compilation, and packaged backend startup/shutdown checks before publication. Windows additionally tests silent installation and uninstall; Mac tests copying the app out of the DMG and running it after the disk image is detached. Every Mac native-library deployment target and loader path is audited for macOS 13 compatibility. macOS 13 runtime testing and live Discord/cloud-provider calls remain outside these automated checks.

Original project source and branding use **0BSD**. The packaged apps include GPL audio codecs and are distributed as combined works under **GPL-3.0-or-later**, with notices included. Each platform has a matching `third-party-source.zip`; GitHub's tagged source archive contains the app's source. See [third-party notices](https://github.com/MaxJafar/DisWhisper/blob/v0.2.1/THIRD_PARTY_NOTICES.md).
