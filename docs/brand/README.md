# DisWhisper brand

The mark is a violet speech bubble containing four white audio bars. It connects the voice input and the written conversation without borrowing Discord's corporate mark.

Original brand assets are under 0BSD:

- `logo.svg`: editable full-color mark.
- `logo-mono.svg`: single-color cutout for small UI surfaces.
- `wordmark.svg`: mark and a system-font wordmark.
- `logo.png`: raster mark.
- `readme-cover.png`: 1774 × 887 README artwork.
- The Windows Assets folder contains the SVG and a multi-resolution ICO used by the executable, tray, and shortcuts.

Palette: violet **#6C5CE7**, light violet **#8C7CFF**, warm charcoal **#14151B**, mint **#39BFA0**. Preserve generous clear space around the mark and use a high-contrast solid background at small sizes. UI typography uses the Windows system font.

## Artwork provenance

The cover was generated using the built-in image generation tool, using the existing original mark as a shape/palette reference. The SVG marks are editable source assets.

Generation brief: a wide 2:1 GitHub cover, restrained dark charcoal and violet, a recognizable speech-bubble/audio-bar mark, legible typography, and a sculptural waveform turning into transcript lines.

Text: “DisWhisper”, “Your conversations, written.”, “Free · Local · Open source”, “Windows now. macOS next.”

Prompt: “Create a polished landscape 2:1 editorial product banner, high resolution, crisp modern typography, restrained premium technology brand, warm dark charcoal background, soft violet light (#6C5CE7 / #8C7CFF) and a hint of mint. The reference image is the established brand mark: a purple rounded speech bubble with four white vertical audio bars; faithfully use that recognizable mark beside the large wordmark. Composition: generous negative space and typography across the left half; the right half has an elegant sculptural rhythm of violet waveform bars turning into calm horizontal transcript lines, subtle dimensional glass and soft light, purposeful and quiet. Not an application screenshot and no fake dashboards. Extremely legible, clean baseline alignment, tasteful rounded geometry. No Discord corporate logo, no mascots, no watermark, no extra text, no stock neon cyberpunk graphics.”
